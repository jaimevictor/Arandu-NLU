# ADR-0036: Final P13 Source And Governance Closeout

- Status: `ACCEPTED_AUTONOMOUS`
- Date: 2026-08-31
- Owners: P13-P14
- Supersedes: ADR-0035 only for the final P13 blocker correction

## Context

Mandatory review of frozen P13 subject
`95d0eda79737d1be180f69f7560d51e619f84758` reproduced five bounded P2
blocker classes and no product, protocol, dependency, cryptographic, or
linguistic defect.

The v8 origin vocabulary dropped three retained Rust-source witnesses in
`bstr`, `fluent-syntax`, and `objc2`. Same-line technical prose could suppress
an earlier genuine origin statement. Markdown-decorated malformed decision
rows could evade both governance parsers. Lifecycle validation accepted
embedded current-phase substrings and incoherent passed or blocked fields.
Finally, verification of an existing extracted crate could enumerate or read
unexpected content before enforcing the archive entry, depth, and byte
limits.

## Decision

Origin discovery MUST restore the three exact retained witnesses and bind
their existing package-rights dispositions. A rejection predicate MUST inspect
only the matched statement, including a bounded same-sentence suffix when the
match does not already end at a statement boundary.

Both decision-row parsers MUST fail closed on decorated malformed candidate
IDs while leaving ordinary prose references untouched. Current-phase
lifecycle identity MUST be a discrete alphanumeric token. Every lifecycle
state MUST bind a state-appropriate subject, evidence checkpoint, queue
checkpoint, finding set, next action, and dependency set.

Existing extraction verification MUST validate the manifest first, bound
directory enumeration before allocation, reject an unexpected path before
opening it, reject a known size mismatch before reading it, stream exact
content comparison, enforce aggregate bytes and entry count, and apply the
same exact path-depth limit used at archive admission.

## Minimum Acceptance And Pass Limit

This is the blocker-only correction authorized by `USR-039`. Exact
regressions and the complete non-Cargo P13 gates MUST pass one immutable
subject. All five source reviewers and all seven phase reviewers MUST report
`PASS` on that same subject with no open P0 through P2 finding. The first
passing subject checkpoints immediately and advances to P14. No optional
final review or refinement pass is permitted.

## Consequences

P13 restores the complete known origin inventory, statement-local rejection,
fail-closed decision parsing, coherent lifecycle binding, and bounded
existing-tree replay. P14 still owns native Linux reachability, product
transport admission, adapter implementation, and Home Assistant packaging.

## Rollback

Keep the transport candidate disabled and record P13 blocked if this bounded
replacement cannot pass its mandatory same-subject gates.
