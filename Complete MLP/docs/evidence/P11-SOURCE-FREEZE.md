## Scope

The P02 train/development corpus already supplies single, parallel-pair,
ordered-pair, coordination-scope, and conflict conformance evidence. It lacks
multi-intent negation gold. The user explicitly authorized the best bounded
workaround, including creation of a source when necessary.

This checkpoint therefore freezes a separate six-record Apache-2.0
`PROJECT_AUTHORED_SYNTHETIC` supplement before P11 composer implementation.
Each train and development split contains one clear first-node negation, one
clear second-node negation, and one ambiguous shared-scope abstention. The
supplement is internal conformance material only. It is not an external
source, independent accuracy evidence, human validation, or a P02 refreeze.

The specification constructs utterances, entity identities, typed expected
graph values, polarity, predicate/argument/negation byte spans, independence,
execution class, and abstention reason without consulting NLU output.
